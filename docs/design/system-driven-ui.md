# System-Driven UI Interactions

## Core Concepts

### Component Queries
- Components query their environment for context
- System state influences available options
- Queries return contextually valid choices
- Results combine explicit and implicit intents
- Decisions based on current principles

### Hierarchical Systems
- New hierarchies can be defined as needed
- Components participate in multiple hierarchies
- Position and role influence behavior
- System state affects hierarchical relationships
- Queries respect hierarchical context

## Intent Resolution

### Explicit Intent

- Validation requirements
- Semantic relationships

### Implicit Intent

- System state implications
- Container relationships
- Accessibility requirements
- Performance constraints
